# Grouping Example

This page demonstrates the convex hulls grouping feature in `force-graph-lib`. The data used here is exactly the same as the main Demo page, but with grouping enabled.

In this example, nodes are grouped by their `platform` property (e.g., `twitter`, `instagram`, `youtube`). The convex hulls feature automatically draws a smooth curve around all nodes belonging to the same group.
